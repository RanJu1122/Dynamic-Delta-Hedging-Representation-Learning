## 一、问题建模总览

### 1.1 核心问题

**定价问题**（Pricing Practice）：
- 给定SVI-JW参数化的隐含波动率曲面
- 推导Dupire局部波动率曲面
- 用Monte Carlo路径验证定价一致性

**研究问题**（动态Alpha对冲）：
- 测量SPX历史数据中隐含波动率的实际粘性行为
- 建立alpha参数与对冲delta的映射关系
- 优化动态对冲策略

### 1.2 数学建模框架

#### 时间约定（双时钟系统）

**两个独立的时间轴**：

```
tau_vol = Business/260    用于：SVI插值、波动率积分
tau_r   = Act/365         用于：forward、discount、drift
```

**为何需要两个时钟？**
- SVI报价基于交易日（Business/260）
- Forward和贴现基于日历日（Act/365）
- 混用会导致 `∫ sigma² dt ≠ w`（原代码bug）

#### 关键定义（两份文档统一）

| 符号 | 定义 | 代码位置 |
|------|------|----------|
| **F(T)** | `F = S * exp(b * tau_r)` | `VolSurface.forward(T, spot)` |
| **y** | `y = ln(K / F)` | `VolSurface.log_moneyness(T, K, spot)` |
| **w(y, tau)** | Total variance | `VolSurface.total_variance(T, K, order)` |
| **sigma_impl** | `sqrt(w / tau_vol)` | `VolSurface.implied_vol(T, K)` |
| **sigma_loc** | `sqrt((dw/dtau) / D)` | `VolSurface.local_vol(T, K, spot_adj, alpha)` |

其中：
- `b = r - q - repo` (cost of carry)
- `D = 1 - (y_adj/w) dw/dy + 0.25*(...) (dw/dy)² + 0.5*d²w/dy²` (Dupire分母)

## 二、Alpha参数约定（核心）

### 2.1 定义

**Alpha参数化smile动力学**：

```python
y_adj = y - alpha * spot_adj
spot_adj = ln(S / S_ref)
```

Alpha进入Dupire分母的y坐标，**不shift隐含曲面**。

### 2.2 三个锚点

| alpha | 名称 | 物理含义 | 代码常量 |
|-------|------|----------|----------|
| **0** | Sticky local vol | local vol曲面冻结 | `ALPHA_STICKY_LOCAL_VOL` |
| **1** | Sticky strike | 行权价固定，BS delta锚点 | `ALPHA_STICKY_STRIKE` |
| **2** | Sticky moneyness | Moneyness固定 | `ALPHA_STICKY_MONEYNESS` |

### 2.3 关键约定（两份文档一致）

#### Pricing Practice文档

```python
# 原始定义
localvol(T, K, spot_adj=0.0)
# 内部计算
y_adj = y - spot_adj * stickiness_ratio
```

#### 动态Alpha研究文档

```python
# 研究约定
alpha ∈ [0, 2]  # 连续插值
y_adj = y - alpha * spot_adj
```

**结论**：
- **定义完全延续**：`stickiness_ratio` 即 `alpha`
- **参数范围**：从 `spot_adj` 的自由值收紧为 `alpha ∈ [0, 2]`
- **物理意义**：从定价工具升级为研究参数

### 2.4 Moneyness 与 Forward 定义延续

**Forward定义（两份文档一致）**：
```python
F(T) = S_ref * exp((r - q - repo) * tau_r)
# tau_r = Act/365
```

**Moneyness定义（两份文档一致）**：
```python
y = ln(K / F(T))
# K = level * S_ref（研究文档中的strike网格）
```

**在MC bump时**：
```python
# spot从S_ref变为S时
spot_adj = ln(S / S_ref)
y_adj = y - alpha * spot_adj  # 这里的y是相对bump后的F计算的
```

##### local_vol 的完整签名（延续定价文档）

```python
def local_vol(self, T, K, 
              spot_adj: float = 0.0,      # 原文档参数
              spot: float | None = None,  # 可选：bump后的spot
              return_diagnostics: bool = False,
              alpha: float | None = None):  # 研究扩展
    """
    alpha参数：
    - None（默认）：使用报价中的StickinessRatio，按tau_vol插值
    - float：强制覆盖所有expiry（研究扫描用）
    
    计算：
        a = alpha_at(T) if alpha is None else alpha
        shift = a * spot_adj
        y_adj = y - shift
        D = 1 - (y_adj/w) dw/dy + ... + 0.5 d²w/dy²
        sigma_loc = sqrt((dw/dtau) / D)
    
    ⚠️ shift只进入Dupire分母，不shift隐含曲面
    """
```

| `y_adj = y - spot_adj * stickiness_ratio` | `y_adj = y - alpha * spot_adj` | 行298 |

## 五、关键定义对照表

### 5.1 Forward 与 Moneyness（两份文档一致）

| 概念 | Pricing Practice | 动态Alpha研究 | 代码 |
|------|------------------|---------------|------|
| **Forward** | `F = S * exp(b*tau_r)` | 同左 | `surface.forward(T, spot)` |

### 5.2 Alpha参数化（研究文档扩展）

| 项目 | Pricing Practice | 动态Alpha研究 |
|------|------------------|---------------|
| **参数名** | `spot_adj` (自由值) | `alpha` (受限值) |
| **取值范围** | 任意float | **alpha ∈ [0, 2]** |
| **物理意义** | 技术参数 | 研究参数（三个锚点） |
| **公式** | `y_adj = y - spot_adj * stickiness_ratio` | `y_adj = y - alpha * spot_adj` |
| **代码实现** | `local_vol(T, K, spot_adj=0.0)` | `local_vol(T, K, spot_adj, alpha)` |

**本质**：
- `stickiness_ratio` 即 `alpha`
- 定价文档中的自由参数，在研究文档中收紧为 `[0, 2]` 区间的连续参数
- **定义完全延续，只是约束更严格**

### 5.3 Local Vol公式（两份文档一致）

**Dupire公式**：
```
sigma_loc² = (dw/dT) / D

D = 1 - (y_adj/w) dw/dy 
      + 0.25 * (-0.25 - 1/w + y_adj²/w²) * (dw/dy)²
      + 0.5 * d²w/dy²
```

**关键**：
- `y_adj = y - alpha * spot_adj` （shift进入D，不shift w）
- `dw/dT` 用 Business/260 时钟（tau_vol）
- 代码实现：`surface.py` 行300-309
